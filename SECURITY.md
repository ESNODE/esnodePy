# Security Policy

## Supported Versions

Only the latest stable release is officially supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.2.x  | :white_check_mark: |
| v0.1.x  | :x:                |

## Reporting a Vulnerability

We take the security of esnodePy seriously.

If you discover a security vulnerability, please **DO NOT** open a public issue on GitHub. Instead, please report it privately:

1.  Email **info@esnode.co** with the subject "Security Vulnerability Report".
2.  Provide a description of the vulnerability and steps to reproduce it.

We will try to acknowledge your report within 48 hours and will keep you posted on our progress.
